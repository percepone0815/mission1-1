# 🎬 영화 티어리스트 메이커 (Movie Tier List Maker)

나만의 영화 취향을 S, A, B, C 티어로 분류하고, 친구들과 링크로 공유할 수 있는 웹 기반 티어리스트 메이커입니다. 사용자 경험(UX)에 따라 두 가지 버전(A, B)으로 구현되었습니다.

---

## 📌 주요 기능

### 📱 버전 A (`영화_A_초안.html`) - 모바일 및 검색 친화형
- **검색 기능:** 영화 제목을 검색하여 원하는 영화를 빠르게 찾을 수 있습니다.
- **모달 기반 티어 배치:** 영화 카드를 클릭하여 팝업(모달) 창에서 직관적으로 티어를 선택할 수 있어 모바일 환경에 적합합니다.
- **맞춤형 영화 추천:** 인기순, 리뷰순, 기분별(킬링타임용 등) 추천 리스트를 제공합니다.
- **읽기 전용 모드:** 공유된 링크로 접속 시, 수정이 불가능한 '읽기 전용 모드'로 렌더링됩니다.

### 💻 버전 B (`영화_B_초안.html`) - 데스크탑 및 드래그 앤 드롭(DnD) 친화형
- **드래그 앤 드롭:** 마우스로 영화 카드를 끌어다 놓는 방식으로 빠르고 재미있게 티어를 분류할 수 있습니다.
- **대기열(Unranked) 시스템:** 아직 평가하지 않은 영화들을 한눈에 볼 수 있는 대기열 영역을 제공합니다.
- **초기화 기능:** 배치된 모든 티어를 한 번에 대기열로 되돌릴 수 있습니다.

### 🔗 공통 기능
- **URL 공유 기능:** 현재 티어 배치 상태를 Base64로 인코딩하여 URL 파라미터로 생성, 클립보드에 복사해 줍니다. (서버 없이 상태 공유 가능)
- **자동 저장:** 사용자가 배치한 티어 상태가 브라우저의 `localStorage`에 자동 저장되어, 새로고침해도 데이터가 유지됩니다.

---

## 🛠 기술 스택

- **Frontend:** HTML5, CSS3, Vanilla JavaScript
- **Data Storage:** 브라우저 LocalStorage
- **No Frameworks:** 외부 라이브러리나 프레임워크 없이 순수 웹 기술만으로 가볍게 구현되었습니다.

---

## 🚀 실행 방법

별도의 서버 구축이나 설치 과정이 필요하지 않습니다.

1. 이 저장소를 클론하거나 다운로드합니다.
2. `영화_A_초안.html` 또는 `영화_B_초안.html` 파일을 더블 클릭하여 웹 브라우저(Chrome, Edge, Safari 등)에서 엽니다.
3. 영화를 티어보드에 배치하고 '공유하기' 버튼을 눌러보세요!
